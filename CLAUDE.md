# teyes-sibir-site — новые SEO-страницы Teyes Sibir

Статический сайт на GitHub Pages: https://tema-mail.github.io/teyes-sibir-site/
Репозиторий: https://github.com/tema-mail/teyes-sibir-site. Push в `main` публикует сайт сам (`.github/workflows/pages.yml`).

## Что это
Черновая площадка страниц Teyes Sibir до переноса на teyes-sibir.ru (Tilda). Каждая страница готова целиком и вставляется в Tilda блоком T123: всё между `<div class="tsb">` и закрывающим `</div>` перед `</body>`.

## Структура
- `index.html` — хаб: готовые страницы и очередь по плану.
- `services/<slug>/index.html` — страница услуги. Slug = будущий адрес на сайте (`/services/cameras`).
- `assets/img/works/` — фото работ (копии с Tilda, сжатые до 960 px).
- `docs/СТРАНИЦЫ.md` — реестр страниц и статусов. `docs/РЕШЕНИЯ.md` — решения.
- `scripts/na_tildu.py` — перенос страницы на teyes-sibir.ru: `--check`, затем `--publish`. Код в Tilda вручную не вставлять.

## Правила страниц
- Стиль сайта: тёмная тема, токены `--tsb-*`, классы с префиксом `tsb`. Один `<style>` на страницу, без инлайн-стилей и мёртвых правил. Mobile-first, только `min-width`.
- Шаблон услуги: короткий ответ → цены → кому нужно → как работает → прайс → этапы → работы → FAQ → контакты. FAQ в JSON-LD слово в слово как на странице.
- Ссылки на страницы этого репозитория — относительные (`../closers/`). На страницы, которых тут нет, — абсолютные на teyes-sibir.ru.
- Все страницы `noindex`, `robots.txt` закрывает сайт: это копии будущих страниц teyes-sibir.ru, дубли вредят SEO основного сайта.
- Цены только «от» и только с живого сайта, с датой. Не обещать «гарантию завода» и децибелы. Фото только реальные. Нет данных — TODO-комментарий, а не выдумка.
- Тексты и база знаний компании: `~/Documents/Teyes-контент/материалы/`.

## Правила работы
- Файл больше 800 строк не дописывать, а выносить новый модуль.
- Делать только то, о чём просили. Никаких попутных улучшений и лишних файлов.
- После каждого рабочего шага — коммит на русском и push.
- Перед правкой прочитать те места, которых она касается, а не догадываться.
- Задача трогает больше трёх файлов кода — остановиться и предложить разбить.
- Чего не знаешь — спросить, а не подставить заглушку и не выдумать.
- Новая страница: добавить карточку в `index.html`, строку в `docs/СТРАНИЦЫ.md`, перелинковку с соседними страницами.
- Владелец сообщает о сбоях словами в чате и в файлы сам не пишет — записывать за ним.
