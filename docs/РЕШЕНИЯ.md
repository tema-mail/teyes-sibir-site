# Решения

**11.10.2026 — площадка на GitHub Pages.** Страницы показываем ссылкой до переноса на Tilda. Выбрали Pages, а не VPS: бесплатно, деплой по push, без сервера. Цена: репозиторий публичный (бесплатный тариф), поэтому внутренние данные (SEO-карта, выгрузки, аналитика) сюда не кладём.

**11.10.2026 — noindex на всём сайте.** Страницы — копии будущих страниц teyes-sibir.ru. Если поисковик проиндексирует github.io, основной сайт получит дубли. Поэтому `robots.txt` закрывает всё, на каждой странице `noindex, nofollow`.

**11.10.2026 — фото работ локально.** Не тянем с static.tildacdn.com, чтобы страницы не зависели от чужого CDN. На Tilda при переносе подставляются адреса фото из её галереи.

**11.10.2026 — перенос на Tilda только скриптом `scripts/na_tildu.py`.** Скрипт сам вызывает MCP Tilda по HTTP и отправляет код файлом. Раньше код перепечатывался в вызов MCP руками: 3–5 минут на страницу и риск опечатки. Теперь 3–10 секунд, код сверяется с файлом байт в байт, живая страница проверяется после публикации. Относительные ссылки скрипт переводит в адреса сайта по полю «Адрес»; ссылка на страницу, которой нет, останавливает перенос. Ключевые слова — поле `keywords` в META (строка «Keywords:»), необязательное, но скрипт предупреждает. Процедуру ведёт скилл `teyes-na-tildu`. В репозитории хранятся id страниц Tilda и адреса фото на CDN (`scripts/tilda_*.json`) — это не секреты; ключ MCP лежит вне репозитория.

**12.10.2026 — страница StarLine в стилистике starline.ru, а не в тёмной теме сайта.** Решение владельца: «бери только стилистку с официального сайта старлайн». Взято: белый фон, голубые полосы секций (#dfedfa), синие градиентные плитки, прямоугольные синие кнопки (#1268a2), оранжевые крупные цифры, синяя полоса сверху карточек, шрифты Open Sans и Roboto. Цвета сняты пипеткой со скриншота starline.ru; оранжевый и синий градиент чуть затемнены ради контраста текста. Логотипы, фото и тексты StarLine не используются: страница — Teyes Sibir. Это исключение из правила «тёмная тема» в CLAUDE.md, только для этой страницы.
